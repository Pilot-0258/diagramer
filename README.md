# 行程图

一个本地运行的个人旅行时间表工具。录入多日行程中的活动与交通后，程序会生成按天分组的时间表，并支持图片、打印和 JSON 备份。

## 当前功能

- 创建、编辑、复制和删除多日行程。
- 添加活动和交通，支持起终点、地点、备注与多种交通方式。
- 交通可以跨日，并与第二天的时间安排一起检查冲突。
- 浏览器本地自动保存，无需账号或云服务。
- 版本化 JSON 导入导出；导入始终创建新副本，不覆盖现有行程。
- 导出整趟行程的 PNG 长图。
- 浏览器打印为 PDF。
- 地图与文字解析尚未启用，但数据结构和适配接口已经预留。

## 运行环境

- Windows 10 或 Windows 11
- Node.js 22.12 或更高版本
- 最新版 Microsoft Edge 或 Google Chrome

## 启动

最简单的方式是双击项目根目录下的 `start.cmd`。

首次运行会自动执行 `npm ci` 安装依赖，然后构建并打开：

```text
http://127.0.0.1:4173/
```

也可以在终端中手动运行：

```powershell
npm ci
npm run local
```

开发时使用：

```powershell
npm run dev
```

请始终通过 `http://127.0.0.1:4173/` 使用正式数据。不要使用 `localhost`、其他端口或直接打开 `dist/index.html`，否则浏览器会视为不同网站，看不到原来的本地行程。

## 数据与备份

行程保存在当前浏览器针对 `http://127.0.0.1:4173/` 的 `localStorage` 中。

- 清理浏览器站点数据、重装浏览器或更换电脑前，请先导出 JSON。
- 图片和 PDF 不包含完整可恢复数据；JSON 才是正式备份。
- 导入备份时会校验版本和结构，并为所有内容生成新 ID。
- 图片、音频、视频和导出产物不进入 Git。

## 分享给朋友

每个朋友需要使用独立的本地副本，各自的数据互不混用：

1. 分享项目源码，不包含 `node_modules/`、`dist/` 和 `artifacts/`。
2. 朋友安装 Node.js 22.12 或更高版本。
3. 双击 `start.cmd`。
4. 需要交换旅行安排时，通过 JSON 文件导入导出。

不要在多个朋友之间共享同一个浏览器配置目录。第一版没有账号、云同步和多人协作。

## 后续地图

地图阶段优先接入高德地图，并通过可替换的 `MapProvider` 适配层调用地点搜索、地理编码和路线规划。由于高德安全密钥不应直接暴露在前端，地图阶段会增加一个仅在本机运行的 Node 小代理。

地图开工前需要重新核对高德最新授权、配额和密钥要求。相关设计记录在 [docs/decisions-travel-planner.md](docs/decisions-travel-planner.md)。
